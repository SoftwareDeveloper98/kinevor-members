## [0.1.0] - 2026-10-20

### Added

- Standalone members backend with the `Member` aggregate, progress entries,
  consents and devices, MediatR commands and queries, EF Core persistence,
  SQLite demo host and platform authorization policies.
- Masked staff directory and profile detail with explicit reveal, registration,
  profile updates and freeze/unfreeze lifecycle actions.
- Member self-service profile, progress timeline, consent grants and
  withdrawals, push-device projections, module-owned JSON export and erasure.
- Angular library with staff directory, member detail, registration and
  self-service components, typed HTTP gateway, facades, providers and routes.
- Angular demo application with the Kinevor visual system, Sora typography and
  Material icons.
- Flutter package with API client, repository, member profile, privacy,
  consent and device screens, theme and strings.
- Flutter example application for Windows and web.
- Real web, mobile and Swagger screenshots under `docs/screenshots`.
- NuGet packing, GitHub Actions CI and tag-based release workflows.
- MIT license and package documentation.
